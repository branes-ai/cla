# Branes.AI Contributor License Agreements

Contributions to Branes.AI open-source projects are accepted under these agreements.

| Agreement | Who accepts it | How |
| --- | --- | --- |
| [Individual CLA](ICLA.md) ([PDF](pdf/BranesAI_Individual_CLA.pdf)) | Every contributor | Comment the acceptance statement on your pull request; the CLA bot records it |
| [Corporate CLA](CCLA.md) ([PDF](pdf/BranesAI_Corporate_CLA.pdf)) | Employers and universities whose people contribute | Signed once by an authorized signatory; send to kishore.kondapi@branes.ai |

See [CONTRIBUTING.md](https://github.com/branes-ai/cla/blob/main/CONTRIBUTING.md) for step-by-step instructions.

Agreement texts are versioned. If a text changes, it gets a new version and a new signature store, and contributors are asked to accept the new version.
