Branes.AI CLA: create the two GitHub Apps

1. Recorder app

Stores signatures and deletes signing requests. Install it on cla and cla-signatures only.

Permissions: Contents, Issues, Actions and Administration (read and write). Administration is needed only to delete signing requests.

2. Recheck app

Re-runs the CLA check after someone signs. Install it on all repositories. It can only re-run workflows; it cannot read or change code.

Permissions: Actions (read and write), Pull requests (read).
